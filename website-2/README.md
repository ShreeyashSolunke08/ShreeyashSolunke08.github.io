## 🎨 Design Philosophy & Features (Website No. 2)

Website No. 2 is styled with an entirely different visual design compared to Website No. 1:

| Dimension | Website No. 1 (Root) | Website No. 2 (`website-2/`) |
|---|---|---|
| **Aesthetic** | Cyberpunk-inspired glassmorphism with high-energy neon glows | Bento Grid / Apple-style minimal dark with clean lines |
| **Background** | 2D Interactive HTML5 Canvas particle constellation | Ambient CSS gradient mesh with subtle scroll parallax |
| **Typography** | Plus Jakarta Sans + JetBrains Mono | Inter + Space Grotesk |
| **Special Widgets** | Interactive CLI terminal simulator + Web Audio synthesizer | Magnetic hover buttons + card spotlight tracking + leadership timeline |
| **Layout** | Filterable project cards with modal case studies | Asymmetric Bento Grid cards with stagger reveals |
| **Color Accents** | Cyan, Sky Blue, Indigo & Purple glows | Electric Blue, Deep Violet, Warm Orange & Emerald |

### Key Highlights of Website No. 2:
1. **Interactive Bento Grid Layout**: Asymmetric responsive cards highlighting core identity, live metrics, and technical expertise.
2. **Scroll-Triggered Reveals**: Smooth Intersection Observer animations revealing sections as you scroll down the page.
3. **Card Spotlight Hover Effect**: Dynamic mouse coordinate tracking creating a radial torch effect over cards.
4. **Magnetic Buttons**: UI buttons that softly follow the cursor on hover.
5. **Interactive Leadership Timeline**: Highlighting Team ByteForge at Code APEX 3.0, EDI1 (ES26102) Group Leadership, and Rajasthan in Focus.
6. **Self-Contained Single File**: Everything (styles, markup, and JavaScript) is packaged cleanly in `website-2/index.html`.

## 🚀 How to Preview Website No. 2

### Method 1: Direct File Open (Instant)
Simply navigate to `website-2/index.html` in Windows Explorer and double-click to launch it in Chrome, Edge, Brave, or Firefox.

### Method 2: Local HTTP Server
From the root directory (`Shreeyash Portfolios`), run:
```powershell
python -m http.server 3000
```
Then visit:
- **Website No. 1**: [http://localhost:3000/](http://localhost:3000/)
- **Website No. 2**: [http://localhost:3000/website-2/](http://localhost:3000/website-2/)

## 🌐 Publishing Website No. 2

If you prefer this Bento Grid design as your primary portfolio website:

### Option A: Make Website No. 2 Your Main Site on GitHub Pages
1. Copy the contents of `website-2/index.html` to replace the root `index.html`.
2. Push to your GitHub Pages repository: `https://github.com/ShreeyashSolunke08/ShreeyashSolunke08.github.io`.

### Option B: Deploy Both Simultaneously
If you keep both folders as they are:
- `https://your-domain/` opens Website No. 1.
- `https://your-domain/website-2/` opens Website No. 2.

### Option C: Free Instant Drag & Drop via Netlify
1. Go to [app.netlify.com/drop](https://app.netlify.com/drop).
2. Drag and drop the `website-2` folder directly into the browser window.
3. Your website will be live in 5 seconds with a custom SSL URL!
