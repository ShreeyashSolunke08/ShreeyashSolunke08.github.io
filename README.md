## ⚡ How to Run and Test Locally

Run a single local web server from this directory:
```powershell
python -m http.server 3000
```
Then visit each edition directly in your browser:
- 🌪️ **Kinetic Motion**: [http://localhost:3000/kinetic/](http://localhost:3000/kinetic/)
- ✨ **Minimal Bento**: [http://localhost:3000/bento/](http://localhost:3000/bento/)
- ⚡ **Cyberpunk Terminal**: [http://localhost:3000/cyberpunk/](http://localhost:3000/cyberpunk/)
- 🏠 **Main Hub**: [http://localhost:3000/](http://localhost:3000/)

> All pages feature an integrated **navigation switcher pill** in their top header, allowing visitors to instantly toggle between `/kinetic`, `/bento`, `/cyberpunk`, and `Hub`.
